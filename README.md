# 📘 NikoShare

[**Русский**](README.md) | [**English**](README_EN.md)

**NikoShare** — система мгновенного обмена ресурс-паками, шейдерпаками и модами прямо в игре через письменные книги.

📥 **[Скачать последнюю версию для Fabric (NikoShare.jar)](https://github.com/nikomia/NikoShare/releases/download/share/NikoShare.jar)**

> 📌 **Требования к клиенту**: Для работы мода необходима библиотека [**Fabric API**](https://modrinth.com/mod/fabric-api).

> 💡 **Независимость компонентов**: Мод и плагин работают как вместе, так и полностью отдельно:
> - **Мод (Fabric)** можно использовать в одиночной игре или на любом сервере без установленного плагина.
> - **Плагин (Paper)** можно установить на сервер без мода — игроки без клиентского мода увидят удобную кликабельную ссылку на скачивание прямо внутри книги.

---

## 🎮 Возможности мода (Fabric)

- 🚀 **Мгновенная загрузка при открытии книги с хэштегом.**
- 📦 **Авто-активация ресурс-паков**: Ресурс-паки скачиваются с плашкой прогресса справа сверху (`0% -> 100%`) и сразу активируются без перезагрузки игры.
- ⏱️ **Защита от зависаний сокета (Socket Timeout)**: Авто-отмена при обрыве связи (таймаут чтения 10с).
- 🔔 **Независимые синие плашки (SystemToast)**: Уведомления от разных файлов выстраиваются параллельно без затирания.

---

## 🛠️ Возможности плагина (Paper)

- 📡 **Авто-выдача ресурс-пака сервера при входе (`auto-resourcepack`)**: Передача ссылок по мод-каналу `nikoshare:auto_pack` с фоновой тихой проверкой обновления кэша.
- 🔄 **Команда перезагрузки конфигурации (`/nikoshare reload`)**: Мгновенное обновление конфига плагина на лету без перезагрузки сервера.
- 🔒 **Защита подписи книг по правам**: Ограничение прав на создание книг с ресурс-паками, шейдерами и модами.
- 🔗 **Автоматическая кликабельность ссылок**: Все ссылки (`http://` / `https://`) в обычных письменных книгах становятся кликабельными для игроков без мода.
- 🎨 **Настройка стилей ссылок**: Кастомизация цвета, подчеркивания и курсива ссылок в `config.yml`.

## 📖 Как делиться контентом через книги

1. Возьмите **Книгу с пером** в Minecraft.
2. На **первой странице** укажите хэштег и прямую ссылку:
   - **`#RP`** — Прямая ссылка на ресурс-пак
   - **`#Shader`** — Прямая ссылка на шейдерпак
   - **`#Mod`** — Прямая ссылка на мод
3. *(Опционально)* На **второй странице** укажите описание с цветовыми кодами `&`.
4. Подпишите книгу и передайте игроку или поставьте на кафедру (**Lectern**).

## 🔐 Права сервера и команды (Paper Plugin)

> ℹ️ **В одиночной игре с модом права не нужны.** Права применяются только на сервере Paper для игроков, подписывающих книги.

| Право сервера | Назначение | Разрешенный хэштег / Команда |
| :--- | :--- | :---: |
| **`nikoshare.sign.resourcepack`** | Подпись книг с ресурс-паками | `#RP` |
| **`nikoshare.sign.shaderpack`** | Подпись книг с шейдерпаками | `#Shader` |
| **`nikoshare.sign.mod`** | Подпись книг с модами | `#Mod` |
| **`nikoshare.reload`** | Выполнение команды `/nikoshare reload` | `/nikoshare reload` |

## ⚙️ Конфигурация плагина (`plugins/NikoShare/config.yml`)

```yaml
# Язык сообщений плагина: "ru" или "en"
language: "ru"

# Форматирование обычных HTTP/HTTPS ссылок во всех книгах
format-general-links: true

# Настройка форматирования текста ссылок (RED, BLUE, GREEN и др.)
link-style:
  color: "RED"
  underlined: true
  italic: false

# Автоматическая выдача ресурс-паков при входе на сервер
auto-resourcepack:
  enabled: false
  urls:
    - "https://example.com/server_pack.zip"

# Проверка прав на подпись книг
require-permissions:
  resourcepack: true
  shaderpack: true
  mod: true
```

## ⚙️ Настройки мода (`config/nikoshare.json`)

Настраиваются через **ModMenu** или в файле `config/nikoshare.json`:

- **Проверять наличие обновления** (`checkUpdates: true/false`) — Легкая проверка новых версий через `version.json` на GitHub.
- **Макс. размер файла до предупреждения** (`maxFileSizeMb: 50`) — Порог размера файла в МБ до показа предупреждения в чате.
